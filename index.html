1. 기초 설정 (The Big Three)

Three.js에서 화면을 띄우기 위해 반드시 필요한 세 요소입니다.

💡
Scene: 무대, Camera: 눈, Renderer: 출력기라고 이해하면 쉽습니다. 
const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(75, sizes.width / sizes.height)
const renderer = new THREE.WebGLRenderer({ canvas: canvas })

renderer.setSize(sizes.width, sizes.height)
renderer.render(scene, camera)

2. 객체 구성 (Mesh)

Mesh는 형태를 정의하는 Geometry와 겉모습을 정의하는 Material의 결합입니다. 

const geometry = new THREE.BoxGeometry(1, 1, 1) // 뼈대
const material = new THREE.MeshBasicMaterial({ color: 0xff0000 }) // 피부
const mesh = new THREE.Mesh(geometry, material) // 완성된 물체
scene.add(mesh)

3. 좌표 및 변형 (Transform)

오른손 좌표계를 기준으로 물체를 제어합니다.

Position Scale Rotation 
// 개별 축 제어
mesh.position.x = 2
mesh.scale.y = 0.5
mesh.rotation.z = Math.PI * 0.25 // 45도

// 한 번에 설정
mesh.position.set(1, 2, 3)

4. 그룹화 (Scene Graph)

여러 개의 Mesh를 Group에 담으면 부모의 움직임을 자식이 그대로 따릅니다. 

const group = new THREE.Group()
scene.add(group)

const cube1 = new THREE.Mesh(...)
group.add(cube1)

group.rotation.y = 1 // 그룹 전체가 회전

5. 카메라 상세 설정

PerspectiveCamera는 원근법을 제공합니다.

const camera = new THREE.PerspectiveCamera(
    75, // fov: 시야각 (세로 방향)
    sizes.width / sizes.height, // aspect: 종횡비
    0.1, // near: 이보다 가까우면 안 보임
    100 // far: 이보다 멀면 안 보임
)

6. 애니메이션 (Loop & GSAP)

화면을 매 프레임 다시 그리는 루프를 생성합니다.

🚀
GSAP: 복잡한 애니메이션을 구현할 때 사용하는 표준 라이브러리입니다. 
const clock = new THREE.Clock()

const tick = () => {
    const elapsedTime = clock.getElapsedTime()
    
    // 물체 회전
    mesh.rotation.y = elapsedTime
    
    // 다시 렌더링 및 루프
    renderer.render(scene, camera)
    window.requestAnimationFrame(tick)
}
tick()

// GSAP 예시
gsap.to(mesh.position, { duration: 1, x: 2 })

7. Geometry (기하학적 구조) 심화

BufferGeometry (저수준 데이터 구조)

개발자가 BufferGeometry를 수동으로 구축할 때는 단순히 "도형을 그린다"는 느낌보다 "메모리 레이아웃을 설계한다"는 관점으로 접근해야 합니다.

  • Buffer의 정의: GPU가 즉각적으로 읽고 처리할 수 있도록 최적화된 연속적인 메모리 덩어리입니다.
  • 자산으로서의 가치: 모든 빌트인 도형은 내부적으로 이를 상속받습니다. 직접 생성 시에는 비어있는 버퍼에서 시작합니다.
  • Typed Array (Float32Array): 일반 JS 배열보다 훨씬 빠르며, GPU 전송 표준 규격입니다. 선언 시 데이터 크기가 고정되며 GPU 메모리 자리를 미리 예약하는 과정입니다.
💡
Vertex Attributes: BufferAttribute는 단순한 숫자 배열에 '의미'를 부여합니다. 예: (array, 3) ➜ "숫자 3개가 하나의 정점(x, y, z)이다"

코드 작성 흐름 및 기술적 디테일

// Step 1 & 2: Raw Data 생성 및 구조화
const positionsArray = new Float32Array([0, 0, 0, 0, 1, 0, 1, 0, 0]) 
const positionsAttribute = new THREE.BufferAttribute(positionsArray, 3)

// Step 3: 속성 등록 (Shader와의 약속된 Key인 'position' 사용)
const geometry = new THREE.BufferGeometry()
geometry.setAttribute('position', positionsAttribute)
선형 메모리 배치 Non-indexed 삼각형 자동 생성
🧐
왜 랜덤 점들이 포개졌나: 별도의 인덱스가 없으면 정점 배열을 3개씩 끊어서 삼각형(Face)을 자동 생성합니다. 정점 간 논리적 연결이 없으면 공간상에서 삼각형들이 제각각 겹치고 파편화된 모습이 나타납니다.

8. Debug UI (lil-gui) 활용

실시간으로 속성값을 변경하며 최적의 비주얼을 찾는 도구입니다.

  • UI 트윅 구성: 반드시 객체의 특정 속성을 인자로 받습니다.
  • Range: min, max, step을 설정하여 슬라이더를 생성합니다.
  • Color: Color Space 관리 문제로 debugObject를 거점으로 사용하는 것이 권장됩니다.
  • Folder: 관련 트윅들을 그룹화하여 관리합니다.
const gui = new lil.GUI()
const debugObject = { color: '#ff0000' }

gui.add(mesh.position, 'y').min(-3).max(3).step(0.01).name('elevation')
gui.addColor(debugObject, 'color').onChange(() => {
    material.color.set(debugObject.color)
})

// 이벤트 리스너
// onChange(): 즉시 실행 | onFinishChange(): 조작이 멈췄을 때 실행 (부하 큰 작업용)

9. 성능 최적화 및 메모리 관리

웹 환경의 한정된 자원을 효율적으로 사용하기 위한 필수 전략입니다.

⚠️
GPU 메모리 해제: JS 가비지 컬렉터는 GPU의 버퍼 데이터를 스스로 지우지 못합니다. 지오메트리 교체 시 반드시 mesh.geometry.dispose()를 명시적으로 호출하세요.
Pixel Ratio

Math.min(window.devicePixelRatio, 2)를 사용하여 고해상도 선명도와 성능의 균형을 맞춥니다.

Aspect Ratio

창 크기 조절 시 카메라 aspect 수정 후 updateProjectionMatrix() 호출은 필수입니다.

OrbitControls & Damping

카메라 이동에 관성(부드러운 가속/감속)을 추가합니다.

const controls = new OrbitControls(camera, canvas)
controls.enableDamping = true

// tick 함수 내부에서 매 프레임 업데이트 필수!
const tick = () => {
    controls.update()
    renderer.render(scene, camera)
    window.requestAnimationFrame(tick)
}
